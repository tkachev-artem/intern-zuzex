# Платформа для ИТ-специалистов

> **Практическая работа выполнена:** Ткачев Артём  
> **Демо/Деплой:** [https://tkachev-artem.github.io/it-lenta/](https://tkachev-artem.github.io/it-lenta/)

---

### **Frontend**
- React 19, TypeScript, Redux Toolkit, SCSS, Saas UI

### Основной функционал

### **Авторизации**
- Регистрация новых пользователей
- Многошаговая форма с валидацией
- Выбор роли

### **Профили пользователей**
- Персональные профили с портфолио
- Редактирование профиля
- Просмотр профилей других пользователей

### **Система создания постов**
- Создание и публикация постов
- Лента с фильтрацией

### **Проекты и портфолио**
- Добавление проектов в портфолио
- Карточки проектов с детальной информацией

## Архитектура проекта

```
📁 src/
├── 📁 components/     # Переиспользуемые компоненты
├── 📁 pages/          # Страницы приложения
├── 📁 features/       # Redux слайсы (auth, posts, profile, projects)
├── 📁 app/           # Конфигурация Redux store
├── 📁 LocalAPI/      # API для работы с данными
└── 📁 assets/        # Статические ресурсы
```

## Запуск проекта

```bash
# Установка зависимостей
npm install
```

```bash
# Запуск в режиме разработки
npm run dev
```

```bash
# Сборка для продакшена
npm run build
```

```bash
# Запуск тестов
npm run test
```
